# D&D WEB VTT — Full Review Snapshot Tool

This tool is for source review only. It does not edit the live project.

Project read from:
`F:\DND WEB VTT`

Output created:
`F:\DND_WEB_VTT_FULL_REVIEW_SNAPSHOT.zip`

Included:
- `src/`
- `server/`
- `public/`
- `scripts/`
- `package.json`
- `package-lock.json`
- `.gitignore`
- `index.html`
- `tsconfig*.json`
- `vite.config.*`
- other root `*.config.*`
- root Markdown files

Excluded intentionally:
- `node_modules/`
- `dist/`
- `data/`
- `.git/`
- `.env*`
- `assets-source/`
- `content-sources/books/`
- campaign/runtime databases
- backups
- binary tools

## How to use

1. Extract this tool anywhere OUTSIDE `F:\DND WEB VTT`.
2. Double-click `Create_Full_Review_Snapshot.cmd`.
3. Wait for `SUCCESS`.
4. Open drive `F:\`.
5. Upload `DND_WEB_VTT_FULL_REVIEW_SNAPSHOT.zip` to ChatGPT.

No code editing is required.
