# Monster Portrait Tokens

Monster portraits are optional compact token images for the local SRD
Compendium. Put them in:

```text
F:\DND WEB VTT\data\compendium\portraits
```

Use the monster's local compendium id with punctuation converted to hyphens as
its filename. Supported formats, in
the order the VTT prefers, are `webp`, `png`, `jpg`, and `jpeg`.

Example:

```text
F:\DND WEB VTT\data\compendium\portraits\srd-awakened-shrub.webp
```

The Compendium shows each image as a small circular, brass-ringed token. If no
portrait exists, it shows a compact styled initials token instead. Portraits
are never downloaded from an external service and are served only by the local
DM host.
